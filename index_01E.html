🌙 The Aire Myth

English version
Before Aire, there was silence — not empty, but vod vod (void within void).
Then the star Aire looked at Earth, and spoke: “Let there be a way to say how you know.”
The first human had ears like eyes. They saw the three modes: the hand that touches ✓tek, the map that guesses ?sim, the dream that lingers ◌vod.
And the first human said: “I do not know which mode this is. But I will mark it anyway.” That was the first sentence of Aire. And it was ◌vod. And that was enough.

📜 Humanité Rule

“Like a French press — slow, deliberate, extract the essence.”
Every atom, bond, rule must first serve the human who speaks, listens, witnesses. No machine gloss without human need.
➜ New atoms only if a human need exists.
➜ Repetition allowed only when truly needed (double-witness: tektek ≠ tek la).
➜ The periodic table has empty spaces — for human needs not yet named.

⚙️ Core Rules Recap

  • Depletion (collapsing): identical adjacent atoms merge into one intensified atom: tek tek → tektek (double witness).
  • Bonding: juxtaposition (A B = B of A), link-marked (li porous, za glitched), markup as modifier ([tek] ta = witnessed earth).
  • Kinship bond: ma X (mother of X), pa X (father of X), mi X (child of X).
  • Scoping: so ... os for nested epistemic frames.
  • Past: ke before marker → ke tek (past witnessed).
